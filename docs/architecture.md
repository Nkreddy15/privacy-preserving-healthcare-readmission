# System Architecture

```text
UCI Diabetic Readmission Dataset
        ↓
Data Cleaning
        ↓
Categorical Encoding
        ↓
Class Balancing
        ↓
Differentially Private Random Forest
        ↓
Prediction Evaluation
        ↓
Race-Based Fairness Analysis
        ↓
Ethical AI Interpretation
```

## Key Techniques

- Class balancing for readmission target
- Differential privacy using `diffprivlib`
- Fairness-aware analysis across race groups
- Readmission prediction and visualization
